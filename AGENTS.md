# Architecture rules
- Use typed local editorial content until a secure CMS is connected, because this project has no configured backend.
- Only approved published content may enter public listings, detail pages, navigation, structured data, or the sitemap, because drafts must not masquerade as published work.
- Preserve superseded site copy in a non-served editorial archive, because unsupported historical claims must remain reviewable without being published.
- Keep per-page metadata and canonical paths centralized, because legacy URLs and future publishing templates need consistent search behavior.
